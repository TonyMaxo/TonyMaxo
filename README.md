## About

**AI Consultant &amp; Systems Architect**

> Business Problems → Technology → Systems → Validation

I work between the business problem and the technology. I don’t start with “how can we add AI?” I start with: **what is actually slowing the business down?**

- Understand the business problem first
- Identify repetitive work and operational bottlenecks
- Decide where AI, software or automation actually makes sense
- Design the system and evaluate models, tools, providers and infrastructure
- Consider permissions, governance, security and cost
- Prototype and validate the architecture

Prototyping is part of the process: I build enough to test whether the design holds.
