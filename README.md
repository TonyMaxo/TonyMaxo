## Run Locally

No build step required — it is a single static file:

```bash
git clone https://github.com/TonyMaxo/tony-max-portfolio.git
cd tony-max-portfolio
start index.html        # Windows (or just open index.html in a browser)
```

An internet connection is only needed for the Google Fonts stylesheet.

## Deploy on Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) → **Import** `TonyMaxo/tony-max-portfolio`.
3. Framework Preset: **Other** · Build Command: *(empty)* · Output Directory: *(root)*.
4. Click **Deploy**. Future `git push` deployments happen automatically.

Any static host works the same way — serve the repository root.
